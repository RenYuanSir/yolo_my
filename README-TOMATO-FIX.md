# 番茄检测排序模型修复方案

## 概述

本项目解决了番茄检测与排序模型在训练过程中出现的关键问题，修复了损失计算、排序逻辑和正样本分配等多个核心问题。现在，模型可以正确地学习检测番茄并对其在串内的成熟度进行排序。

## 主要问题

1. **无正样本问题**：fg_mask全部为False，导致box_loss和dfl_loss为0
2. **排序损失逻辑错误**：误解了高度表示和成熟度表示方式
3. **特征通道处理不当**：无法正确处理h_pos特征

## 修复方案

我们提供了一个补丁文件`tomato_model_fix_patch.py`，可以在不修改原始代码的情况下动态修复所有问题。方案包括：

1. **改进正样本分配**：
   - 扩展真实边界框（增加10%）以增加与预测框的重叠
   - 调整TaskAlignedAssigner参数，提高正样本分配率

2. **修正排序损失计算**：
   - 正确理解高度表示：h_rel=0为顶部，h_rel=1为底部
   - 正确理解成熟度表示：类别值越小表示越成熟（0-fully ripe, 3-green）
   - 增加基于h_pos特征的排序损失计算

3. **完善特征处理**：
   - 增强特征处理逻辑，支持多种模型输出格式
   - 提高代码健壮性，添加异常处理

## 使用方法

在训练脚本的开头添加：

```python
from tomato_model_fix_patch import apply_patches
apply_patches()  # 应用所有补丁

# 继续正常的训练流程...
```

## 修复效果

- **边界框损失和DFL损失**：从0变为有效值，参与训练过程
- **排序损失**：可以根据高度和成熟度关系动态计算
- **h_pos特征学习**：模型可以端到端学习垂直排序关系
